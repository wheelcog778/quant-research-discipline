# 量化研究：预注册与判死机制

> 别骗自己：先预注册，再独立验证，不达标就判死。

一套工具 + 一本判死案例集，只干一件事：**在把钱投进去之前，判断一个信号是不是真的**。它不是策略库，它是杀策略的那套机器。

- 纯 Python 标准库（3.9+），零依赖
- 数据全部 CSV，任何语言 / 任何 agent 都能产出
- 自带 18 项自检：先证明工具能分辨真假，再用它下结论

---

## 为什么要有这套东西

回测翻车的原因大多很朴素，且都是"晚发现很贵、早排除很便宜"：

- 规则是看到结果之后才定的（没有预注册）
- 日期区间没有事先钉死
- 试了一组参数不满意，又试了二十组
- 样本里没有退市股
- 用噪声底 3% 的样本声称 2% 的效应
- 第二个复核的人还是自己，或者还是同一个 prompt

这个仓库把这些对策打包：预注册模板、七道关卡的工具包、MDE 计算器，以及八条最终结论为"不行"的真实研究线。

## 30 秒验证

```bash
python vkit/scripts/vkit.py selftest     # 18/18 全过才可用
python vkit/scripts/vkit.py --help       # 六个命令
python docs/tools/mde.py --sigma 20 --n 100 --alpha 0.05 --power 0.8
```

工具吃 CSV：一行一个（日期，代码），带一列未来收益和你正在检验的因子。

## 七道关卡

| # | 关卡 | 回答的问题 |
|---|---|---|
| 1 | 数据完整性 | K 线是真的、全的、顺序对吗？ |
| 2 | 点时性 | 这条信息在那一天真的可得吗？ |
| 3 | 预注册 | 规则、样本、阈值是不是跑之前就冻结了？ |
| 4 | 多重检验 | 这个结果之前试过多少个变体？ |
| 5 | 效应量 | 效应比噪声底（MDE）大吗？ |
| 6 | 稳健性 | 换子区间、换定义、加成本还成立吗？ |
| 7 | 独立复核 | 有没有第二个人从产物重算过？ |

全文见 [`vkit/references/gates.md`](vkit/references/gates.md)。

## 八条判死案例

每一条都是真实研究线，都以判死收场，并附上杀死它的数字（07 例外：它记录的是一次在出数前就按约定停止的复审）。名称已脱敏，算术没有。

| # | 研究线 | 结论 |
|---|---|---|
| 01 | Q/V 池历史基线 | Q 池判死：20 日 −0.80pp（t −1.51）、60 日 −1.72pp（t −3.24） |
| 02 | 出场规则（V5.4） | 出场翻不正负期望；外部声称的 +1.08% 不可复现 |
| 03 | 过滤器消融 | 过滤器确实在赔钱，但它赔的是 β 不是 α |
| 04 | 池子补全（含退市股） | 补进 211 只退市股后结论不变：无可用 alpha |
| 05 | SUE | 判死：2010–2017 无市值数据，做不了样本外复活 |
| 06 | ST 撤销腿 | 判死：MDE₈₀ 2.96pp，卡在 2.0pp 门槛外——是噪声，不是没有效应 |
| 07 | 板块抱团 | 早先的 L1 判死维持；本记录是复审，在输入门（日期越界）按约定停止，未产出新数字。早先的数字不在本仓 |
| 08 | 公告闸门 | 否决：主检验没过预注册线，不建闸门 |

索引：[`docs/case-studies/README.md`](docs/case-studies/README.md)。

## 为什么"判死"才是产品

诚实的研究过程，产出的大多是否定结果。只报喜的流程不是流程，是营销。公开这八条判死记录本身就有价值：每一条都省下了本来要拿去交易噪声的钱。

预注册模板要求在任何数字产出之前写清四件事：假设、样本（含退市/停牌如何处理）、判据（带 MDE 计算）、停止条件。

## 已知边界

- 案例背后的原始面板不在仓库里。数字照实报告，原始数据不可再分发。
- MDE 计算器假设观测独立。重叠窗口需要用有效样本量；工具会打印自己的假设，不会假装没事。
- 单机、文件式流程。没有执行、没有组合记账、没有实盘。
- 统计关卡不能证明信号为真，只能让"骗自己"变难。

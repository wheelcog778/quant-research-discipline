## 三、判级理由

- V4 按 v1 判据形式全过：差值 +0.699pp、t 3.54 ≥ 2.58；3/3 年更好；IC 不比 V0 差；容量够。**按 v2（IC>0）不过。**
- **但 IC 仍为负**（−0.0065，t −1.83）：在低流动性半区里，分数依然没有正向排序能力。V4 的收益来自池子（小盘/低流动性溢价），不是选股。
- 分年也不稳：V4 在 2021（−1.87%）和 2026（−3.26%）为负，靠 2020（+4.41%）撑起均值。
- V2/V3 方向一致：V2 t 1.81（不显著）、V3 t 2.45（过 1.96、不过 Bonferroni 2.58）——**少交过路费，但不足以翻正。**
- 自评两条：
  1. 预注册里我写「V4 不可交易（容量/冲击）」，实测容量够——这条先验被自己的数据推翻。
  2. 判据第 3 条只要求「IC 不比 V0 差」，没要求「IC > 0」，所以 V4 形式通过但实质是 β。**判据写松了，这是设计缺陷**，v2 应改为「IC > 0 且 t ≥ 2」。

## 七、未覆盖边界

1. 成交额用 `volume × close` 估算（sina 无 amount 字段），阈值边界股可能有个位数出入。
2. 未建模涨跌停/停牌不可成交；低流动性端冲击成本按 0.2% 常数，未随规模变化。
3. 分年只有 7 段，2020 只有 5–6 个稀疏调仓期，V4 的正号有相当部分来自这一段。
4. 未测「全池扫描」的工程代价（GUI 耗时、数据源限流）——这是改产品前必须先量的。
5. 创业板/科创板、北交所不在池内。

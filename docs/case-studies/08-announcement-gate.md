## 1. 结论

**主检验不通过 → L1，停手。** 减持公告在「尾盘 14:45 可见 → 持有 5 个交易日」口径下
**没有负向信号**（+0.19pp，t = +1.21，簇稳健 t = +1.60），方向与假设相反；
解禁公告同样为零效应（簇稳健 t = +0.09）。

按预注册规则，主检验失败即判死，**不建减持/解禁拦截闸门**。

副产物（探索性，不参与判活）：监管类公告（立案/处罚/问询函/关注函）与业绩预亏，
5 日均值不显著，但**5 日内超额跌破 −10% 的概率是对照的 3 倍**（11.6% / 11.4% vs 3.8%）。

## 2. 口径

全部取自 `P1P2-口径卡-2026-11-03.md` §4，本轮一字未改。关键三条：

- 事件可用日：公告披露时刻 ≤ 14:45 → 当日；否则次一交易日（防前视，用东财 `display_time` 精确到秒）
- 收益：`EX5 = 个股 T→T+5 收益 − 沪深300 同期收益`，后复权，5 个交易日
- 主检验：`REDUCE`（减持）类的 EX5 均值，通过线 **≤ −1.0pp 且 t ≤ −2.6**（口径卡 §4.6 的 MDE 门槛是 1.46pp，两者同时不满足；结论不受影响，见 §6 重算）；
  MDE 按实测 σ 与聚簇独立单位重算：σ = 7.14pp、N = 211 只有减持事件的股票 → **MDE = 2.8×7.14/√211 = 1.38pp**。原稿用 2027 条事件当独立样本得到 0.44pp，违反本轮自己的簇相关口径，已更正。

## 4. 判级理由（L1）

1. 主检验点估计 **+0.19pp**，与「减持利空」假设方向相反，t 值远离 −2.6 门槛
2. 点估计 +0.19pp 与主假设反向；按 211 个股票簇计算的 MDE 为 1.38pp，不能再用错误的 0.44pp 宣称“若有效应就一定能看见”
3. 减持的年份符号 `-+-+--+`，7 年里 4 负 3 正，无稳定方向
4. 解禁更干净：均值 +0.35pp、簇稳健 t 0.09、尾部概率与对照完全相同（3.8% = 3.8%）
5. 副产物未过预注册的第二道门槛（Bonferroni t 2.9）：REG −2.65、BADWARN −2.44 均未达线，
   **不得在本轮升级为判活依据**

## 5. 可信度与边界

- **簇相关已处理**（簇稳健 t 与普通 t 并列给出）；BADWARN 在簇稳健下从 −2.44 掉到 −1.13，
  说明它的路径主要来自少数几只票，不可信
- **未做 cluster-robust 的回归控制**（行业/市值/波动）：5 日超额里有市值因子残留，
  小盘股天然跑赢沪深300（对照组均值 +0.28pp 就是这个残留）
- **单一 regime 未分层**：2020-2026 跨了牛熊，但没有按大盘档位分组，跌市里减持的效应可能更强
- **无成交约束**：本研究问「有没有信息」，不建模涨跌停/停牌能否成交（那属另一层）
- **ST 类的正向结果不可用**：它主要由「停牌 → 复牌」构成，重组复牌暴涨是已知现象，不是可交易边缘
- **样本期止于 2026-09-30**，未做样本外
- 事件识别只看标题关键词，**不看正文**：`减持` 里混着「减持结果」「减持进展」，
  敏感性版本（仅减持计划预披露）未单独跑

## 7. 可引用的三条事实

1. 减持公告（2027 条，309 只票，2020-12~2026-09）在 5 日口径下 **无负向效应**：+0.19pp，t=+1.21
2. 解禁公告（688 条）**无任何效应**：均值 +0.35pp，簇稳健 t=0.09，尾部概率与随机日完全相同
3. 监管类与业绩预亏的**均值不显著，但 5 日内跌超 10% 的概率是对照的 3 倍**（11.6% / 11.4% vs 3.8%）

## 8. 没覆盖什么

- 30/60 日持有期：减持的供给压力论本来讲的是 3–6 个月，5 日看不到是预期的；本轮只预注册了 5 日
- 「近 30 日内曾有减持」的存量口径（用户原始的「下单前 60 秒核验」场景）：本轮测的是事件当日
- 减持方身份（大股东 / 董监高 / 创投）：标题不可靠，需解析 PDF
- 监管类的细分：立案/处罚与问询/关注函混在一类，前者是尾部事件、后者常是例行公事
- 期望差：市场是否已提前知道减持（需一致预期数据，本机没有）
- 影子模式：产品未接线，没有实盘并行记录

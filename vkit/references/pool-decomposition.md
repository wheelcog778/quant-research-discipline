# 关 6.5 · 池子分解与选股消融

为什么单开一关：分组 IC（按 cat/regime 分开算）只回答「在哪一组里排序有效」，
回答不了更前面的问题——**这套策略选的那个池子，未来是不是本来就在跌。**
组合亏钱时，下面两件事能同时成立：

1. 组内 alpha 为正（在池子内部，分数确实能分出好坏）；
2. 净值大幅为负（因为整个池子在跌，分得再好也只是跌得少一点）。

把 (2) 误读成「选股能力为负」，就会去优化特征、调分数权重，而真正的问题是门槛立错了。
用 `scripts/pool_lab.py` 一次扫描出两张表，把这两件事分开。

## 一、池子表：给「门槛」标价

每个池子各自等权持有，相位链式算净值（资金分 H 份，每份一个相位，等价每日 1/H 换仓）：

```bash
python scripts/pool_lab.py --db audit.db --fwd 5 --tops 5,20 --cost 0.002 --drop eliminated
```

输出里有 `KEPT`（门槛放行的）与 `DROPPED`（门槛剔掉的）两行，两者之差就是：

> **过滤器成本 = DROPPED 毛收益 − KEPT 毛收益**

实测一例（A 股 2021-01→2026-10，3018 只，持有 5 日）：

| 池子 | 日均只数 | 毛累计 | 净累计（0.2%） |
|---|---:|---:|---:|
| 全池 | 2848 | +55.6% | −50.6% |
| **DROPPED（被剔除的 82%）** | 2333 | **+84.7%** | −41.4% |
| **KEPT（允许买的 500 只）** | 499 | **−45.3%** | −82.7% |
| risk 组 | 17 | −99.4% | −99.8% |

过滤器成本 = **130 个百分点**。这个数字单独写进报告，它比任何 t 值都更能说明问题。

**归因边界（必须写）**：被剔除池通常以中小盘为主，这 130pp 里混着**小市值 beta**，
不能全部记在「规则写错」账上。没有行业/市值中性化时，只能说「站在风格逆风侧」，
不能说「规则有 bug」。这句话不写，报告就是拿风格当结论。

## 二、选股消融：只换「选谁」这一层

同一批分数、同一批收益，只换选股规则，看 alpha 与净值的组合形态：

| 规则 | 含义 |
|---|---|
| `abs_top` | 跨类取绝对分 top-N（产品最常见的写法，也是错得最隐蔽的） |
| `percat_top` | 类内各取 top-N |
| `pct_top` | 类内百分位后跨类比（唯一能直接比较跨组强弱的写法） |
| `pct_top5pct` | 类内百分位 ≥95% 的全体，不固定只数 |

## 三、判读铁律（四种形态）

| alpha | 净累计 | 结论 | 下一步 |
|---|---|---|---|
| 正 | 正 | 选股与池子都对 | 走关 6 并列敏感性 + 关 7 组合层 |
| **正** | **负** | **池子在跌，问题不在选股** | **重设门槛 / 换池子，别调特征** |
| 负 | 负 | 选股规则本身有害 | 查是否跨类取绝对分（分数不可比时必然为负） |
| 负 | 正 | 靠池子 beta 活着，选股在倒扣 | 换基准重算，看扣 β 后还剩什么 |

实测那一例：10 种规则 **alpha 全部为正**（+0.125%~+0.364%/期，t 最高 +4.31），
**净累计全部为负**（−38%~−78%）→ 落在第二行。所以「换选股规则」这条路被排除了，
要动的是门槛与换手，不是特征。

## 四、什么时候会把这张表算错

1. **基准用错**：alpha 的分母是「同池等权」。用全池（含被剔除组）当分母，
   会得到负 alpha；用保留池当分母会得到正 alpha。同一批股票两个符号——**必须写明分母是哪个池**。
   一个策略相对全池等权 −0.23%/5 日、相对保留池等权 +0.20%，两条都对，说的是两件事。
2. **不给固定种子**：随机对照组至少 20 次取中位，单次随机会把运气当结论。
3. **重复 shift**：fwdH 已经含了「T+1 收盘买入」，再 shift 一次就是未来函数。
4. **丢掉未平仓**：最后一个 cohort 按可得 fwd 计入，不要直接丢，否则净值尾部被系统性剪掉。
5. **当上线证据**：这是简化模型（无止损、无仓位上限、无容量），只能比大小，不能当收益承诺。

6. **并列拿未来收益破平**（实测踩过，最狠的一个）：同分是常态——封顶组（`min(score,35)`）、
   托底组、离散打分器的整数档都会大量同分。若排序写成 `sorted([(score, ret)])`，
   第二关键字是未来收益，等于在每一个同分组里挑出「后来涨得最多的」。
   实测后果：alpha 从 +0.13%/期被抬到 **+5.96%/期（t+89）**，净值从 −16.7% 抬到 **+4.2e14 %** ——
   数字大到荒谬反而容易发现；危险的是同分组少、污染只有 0.05%/期的时候，看起来完全合理。
   **破平只能用确定性键**（sym 代码序或固定哈希），且**换一个破平键再算一遍**：
   两个键下 alpha 差很多，说明结论由并列切分决定，不能引用（与关 6 并列敏感性同一件事）。

## 四½、工具自带的自检

用 `pool_lab.py` 时把 `--tie code` 与 `--tie hash` 各跑一次，两者 alpha 差距应在噪声量级。
差出倍数就是并列污染，先停下来查排序键，不要解释经济含义。

实测结论（需要记住的强弱排序）：

| 选法 | alpha code → hash | 结论 |
|---|---|---|
| 跨类取绝对分 top-N | +0.199% → +0.189%（t 3.75→3.51） | 稳，可引用 |
| 每类各取 top-N | −0.264% → −0.263%（t −6.83→−7.15） | 稳，可引用 |
| 类内百分位 top-N | +0.152% → +0.096%（t 3.07→**2.10**） | 打七折，**不可引用** |
| 类内百分位 ≥95% | +0.126% → +0.078%（t 3.45→**2.21**） | 打六折，**不可引用** |

**反直觉的一条：百分位法恰恰是并列污染最重的选法。** 因为它的间隔是 1/n，
而并列把同一分值的股票切成相邻的假序——看起来最像「科学归一化」的写法，最容易被并列筛成假信号。
所以千万不要用百分位法的结果去证明「归一化后信号变强了」，先过并列复核再说。

7. **相位链式的单值不稳，只比值差**：净值按「资金分 H 份、每份走一个相位」链式时，
   累计收益对「每个相位从哪天开始换仓」敏感。两个实现同口径、只差有效天数（1439 vs 1425），
   同一个池子能算出 +84.7% 和 +74.2%。**这不是算错，是噪声**：每相位只有 ~285 次复利，
   起点挪一天就能差 10pp。所以：报告里只引用 **KEPT 与 DROPPED 的差**（实测 127–130pp，两实现一致），
   不引用单池的精确累计值；要更稳就用日频盯市而非相位链式。

## 五、与其它关的顺序关系

```
第 0 关 构造效度（分数有没有资格被排序）
   ↓
关 1–5 IC / 衰减 / 分段 / 分年 / 成本   ← 全在这个分组内做
   ↓
关 6 集中度（类别构成 + 并列敏感性）
   ↓
关 6.5 池子分解与选股消融  ← 本关：先分清是选股还是池子，再进组合层
   ↓
关 7 组合层（净值 / 换手 / 回撤）
```

顺序不能省：没做 6.5 就直接做关 7，会看到一个亏损的数字，然后猜它来自选股还是成本——
两者差着一个数量级的整改成本。

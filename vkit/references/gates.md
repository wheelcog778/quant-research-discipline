# 七关判定标准（v1.3）

> 每一条阈值都来自实测，不是教科书抄来的。标「实测」的数字可以在
> `references/case-study.md` 里找到出处。

---

## 关 1 · IC / t：有没有信息

**口径**：每日横截面上，因子排名与未来收益排名的 Spearman 秩相关。
用秩相关不用普通相关——涨停、闪崩、停复牌造成的极端值会绑架普通相关。

**n 是横截面天数，不是股票数。**

**必须用 t_HAC，不是 t 朴素。** H 日前向收益是重叠的：今天的 5 日收益与明天的 5 日收益共享 4 天，
IC 序列因此自相关，朴素 t 会高估。`vkit ic` 同时给出两个值，判定以 t_HAC 为准。

| 指标 | 垃圾 | 勉强 | 能用 | 很强 |
|---|---|---|---|---|
| 日频 IC 均值 | < 0.01 | 0.01~0.02 | 0.02~0.05 | > 0.05 |
| IR（IC 均值/标准差） | < 0.03 | 0.03~0.05 | 0.05~0.15 | > 0.15 |
| \|t_HAC\| | < 2 | 2~2.6 | 2.6~3 | > 3 |

**多重检验门槛**（Bonferroni，α=0.05）：

| 一共试了几次 | 需要的 \|t\| |
|---|---|
| 1 | 1.96 |
| 4 | 2.50 |
| 6 | 2.64 |
| 12 | 2.87 |
| 20 | 3.02 |

"试了几次"要如实算：不同参数、不同持有期、不同样本段、不同分类口径，**每个都算一次**。
实测教训：板块层那次 4 个变体 × 3 次重跑 + 纯度切分 2 组 + 持有期 3 个 ≈ 12 条路径。

**IC 过高是警报，不是好消息。** 真实因子的日频 IC 极少超过 0.10。看到 0.3 以上，
先查前视/未来函数/数据泄漏，再谈显著性。`vkit ic` 会自动打这条警告。

## 关 2 · 衰减：信息能撑几天

| 形态 | 含义 | 处理 |
|---|---|---|
| 20 日还剩 60% 以上 | 低频、基本面对 | 可长持，成本不敏感 |
| 5 日掉到 20% 以下 | 短周期情绪 | 必须快进快出，成本吃掉一切 |
| **负值随持有期单调放大** | 稳定的反向关系，不是噪声 | 噪声不会在 1/5/10/20 四个尺度同向递增 |
| 符号在持有期间跳变 | 结构不稳 | 先查样本，再谈信号 |

实测：110 分制 1/5/10/20 日 IC = −0.0129 / −0.0221 / −0.0267 / −0.0293。

## 关 3 · 分段：是不是被某一段主导

| 形态 | 分段结果 | 含义 |
|---|---|---|
| 一直有效 | 每段同号、量级接近 | 真信号（仍要防样本期只覆盖一种行情） |
| 一直无效 | 每段都在 0 附近抖动 | 没有信息，立刻停手 |
| 某段崩了 | 一两段极端值主导均值 | 结构性风险，需要 regime 过滤 |
| 全段同号但极端 | 8/8 段都负 | **一致无效**，别再迭代公式 |

## 关 4 · 分年：它还活着吗

**这是最容易被跳过、也最容易翻转结论的一关。**

做法：把每一年单独算一遍 IC / 分组收益，看形态。

| 年份形态 | 判定 |
|---|---|
| 每年同号、最近一年仍同号 | 通过 |
| **早期正、最近一年转负** | **近期证据不支持继续使用**；需要预设样本外验证才能重新启用。**这不等于"永久失效"**——也可能是噪声或 regime 变化 |
| 年与年之间正负交替 | 无信息，别包装成"conditional alpha" |
| 只有 1–2 年大正、其余接近 0 | 不是信号，是那两年的 beta |

实测：某分数段六年整体 IC +0.0093（t=2.69），按年拆：2021–2024 全正，2025 衰减，2026 三个样本全为负。
正确处理是"拒绝上线 + 要求预设样本外"，而不是判它永远无效，也不是拟合一个 regime 开关。

## 关 5 · 经济量级：扣成本还剩多少

| 问题 | 用什么回答 |
|---|---|
| 有没有关系 | IC 的 t_HAC |
| 关系有多大 | 分档首尾差（**有符号**，%，不是 t） |
| 往哪个方向做 | 价差的符号：低−高为负 = 多高档、空低档 |
| 扣成本还剩多少 | 多头腿超额 − 单边成本；可做空时才是 \|价差\| − 两腿成本 |

**先看价差量级，再看 t。** t 值靠样本量堆，样本一大什么都显著。

**方向必须由数据定，不能预设。** v1.2 及以前一律按「低−高 − 成本」算：正向因子（高档更强）
的低−高是负的，扣成本后必然更负，一个每天高减低 2% 的因子会被判成 L3 不可实施。
现在先由符号决定做多哪一档，再扣成本；表里同时给"多空"和"只用多头腿"两列。

A 股双边成本参考：佣金万 1 + 印花税千 1（卖出）+ 滑点 ≈ **0.15–0.25%（每腿）**。

**零售默认不能做空**：可实施口径取「多头腿超额 − 双边成本」。多头腿超额是相对当日全池均值的
超额，不含市场 β——它能赚钱不等于能跑赢指数。

实测：5 日 IC = −0.022（t=−7.98），十档首尾差只有 **0.18%/5 日**，不够付手续费 → **L3**。

## 关 6 · 集中度：收益是不是全在几天

**必须同时回答两问，只答一问会误判。**

**问一：剔掉贡献最大的几天，还剩什么？**

| 结果 | 含义 |
|---|---|
| 剔 20 天仍为正、缓慢衰减 | 收益分布健康 |
| 剔 5 天就转负 | 高度集中，均值不可代表策略 |
| 单日贡献占比 > 40% | 先查那天发生了什么 |

**问二：那些日子，事前能不能识别？**

| 事前可识别 | 例子 | 判定 |
|---|---|---|
| **不可识别** | 救市日、突发政策、黑天鹅 | 集中度即否决——你无法重复它 |
| **可识别** | 财报季、指数调整日、期权到期、固定事件 | 集中度**不构成否决**，但必须改写为事件策略，并把阈值搜索计入尝试次数 |

同时看**按日等权**（一天一票）与池化均值：两者差得远，说明少数日期样本量爆炸，
池化均值被绑架（辛普森悖论）。

实测：某反转类池化 +6.58%，按日等权 **−0.697%**；剔 5 天 −0.121%。被剔的是救市日 → 事前不可识别 → 否决。

## 关 7 · 组合模拟：风控/离场规则值不值

**不能用均值一条判死。** 离场规则即使降低均值，也可能改善尾部、波动、资金占用。

输出必须同时看四项：

| 指标 | 说明 |
|---|---|
| 均值 / 中位 | 收益 |
| p5 / p10 / 最差 | 尾部（风控的主要价值通常在这里） |
| 波动 | 风险调整后的比较 |
| 平均持有天数 | 资金效率与换手 |

判定顺序：

1. 先看尾部是否显著改善（p10 收窄多少）。
2. 再看均值的代价是多少。
3. 再比「平均差」与「按日等权差」——符号相反说明少数日期在主导。
4. 最后看显著性，而且要看**两个 t**：日期聚类 t 只处理同日相关；持有 H 日的交易还共享
   H-1 天行情（相邻信号日重叠），必须再过「t(重叠校正)」和它对应的门槛。
   合成数据实测：只有日期聚类时，零均值重叠样本的假阳性 **46%–69%**（名义 5%）；
   加上按日等权 + 平坦权 HAC + t 临界值后回到 **5%–8%**。
5. 门槛是有效自由度下的 t 临界值（≈ 天数/(2H−1) 决定 df），不是 1.96。
6. 有效自由度 < 3（信号日少于约 6H 天）时，这个校正本身估不出来，工具输出「不可估」。
   **不可估 ≠ 不显著，也 ≠ 显著**：样本不够做这个检验，只能说没有证据，不能说没有效应。

**这一关不是上线证据。** `sim` 没有仓位、资金曲线、成交与容量模拟；它只能回答
"同一批入场，哪种离场规则的收益/尾部/換手更好"，不能回答"这个策略能不能上钱"。

**结论表述必须是交换句，不是判决句**：
「以 X% 的均值，换 Y 个点的左尾改善，是否值得取决于仓位与账户承受力」——
而不是「这是负期望，扔掉」。

实测：某策略止损把 p10 从 −14.57% 收到 −7.64%，代价是均值从 +0.279% 变成 −0.254%，
按日期聚类的 t = −3.36（朴素 t = −21.98；这一关 v1.3 还要求再报重叠校正 t，案例数据不足未重算）。
**均值口径下是负的，尾部口径下是有价值的**——
这正是必须分级、不能二元判死的原因。

## 横向检查 A · 标签核对

审计库里"类别 X 有效"时，**必须去代码里确认 X 到底由哪个分支产生**。

实测事故：报告写"`risk`（跌破 MA20 / 触及止损）−1.76%，t=−11.81，唯一活着的信号"。
实际审计调用 `analyze()` 时没传 `locked_stop` 也没传 `is_watched`，两个分支恒为 False，
`risk` **只可能**由"四连板妖股"分支产生。抽查 300 条，命中 300/300。

检查办法：把统计标签反查回代码分支，用十来条样本验证分支条件成立，再引用这个标签。

## 横向检查 B · 择时

信号触发日之后，指数（或等权全市场）未来 h 日的收益，与非触发日比。
**H 日前向收益重叠，必须用 t(HAC)**；多个阈值 = 多次尝试，门槛要按 Bonferroni 抬高。

| \|t(HAC)\| | 判定 |
|---|---|
| < 2 | 没有择时能力，别用"信号日之后大概率反弹"叙事 |
| > 门槛且逐年稳定 | 可作为择时层，但仍需做集中度检验 |

注意指数（市值加权）与等权全市场可以给出相反结论，两个口径都要过线。

实测：某信号 ≥3 只触发时，差 −0.04pp，t 朴素 −0.14 / t(HAC) −0.08 → 无效。
（v1.2 前的 HAC 实现漏了一次归一化，把 t 放大近 2 倍，已修正并加入自检校准。）

## 交付报告模板

```markdown
# <策略名> 检验报告

## 0. 判级
L0 / L1 / L2 / L3 / L4 / L5 —— 一句话理由
（若数据或口径不足，首页必须写：**仅方法演练，不可引用**）

## 1. 口径
- 数据源、复权方式、样本（只数 × 天数 × 观测数）
- 买入时点、前向收益定义、超额基准
- 多重检验：本次共 N 次尝试，|t| 门槛 X
- 成本与成交假设（佣金、印花税、滑点、涨跌停、停牌）

## 2. 七关结果（只放数字）
| 关卡 | 结果 | 判定 |
|---|---|---|
| IC/t | IC=x, t朴素=y, t_HAC=z | ... |
| 衰减 | ... | ... |
| 分段 | ... | ... |
| 分年 | ... | ... |
| 经济量级 | 首尾差 vs 成本 | ... |
| 集中度 | 剔5天=x；这5天事前可否识别 | ... |
| 组合模拟 | 均值/尾部/换手/t聚类 | ... |

## 3. 判级理由
不是"结果不好"，而是逐条列出被排除的解释：
- "样本太短" → 已用 N 年、X 只复跑，同向
- "持有期不对" → 1/5/10/20 全负
- "再调参数" → 两套参数同向
- "反着做" → 反向 t=X，不显著 / 不能做空

## 4. 数字可信度速查
| 数字 | 能否引用进产品 |
|---|---|
| ... | ✅ / ❌ + 原因 |

## 5. 边界
前视、幸存者、样本外、成本、成交假设未覆盖的部分。
```

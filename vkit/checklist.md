# 门禁清单（唯一"可提交"定义）

任一 `✗` → 报告不可提交，结论强制降级到 L0 或 L1。
逐条必须能由第三方复核：**没写命令 = 没做。**

## A. 数据与口径

- [ ] A1 样本写明：标的数 × 交易日数 × 观测数，日期区间明确
- [ ] A2 复权方式写明（前复权/后复权/自建），跨源交叉验证做了一致性检查
- [ ] A3 股票池定义写明（含不含 ST、退市、新股），未覆盖的部分承认是 universe 限制，**不声称"无偏差"**
- [ ] A4 幸存者偏差单独讨论；**不假设**负向结论天然稳健
- [ ] A5 成本写明：佣金、印花税、滑点、涨跌停买不进、停牌
- [ ] A6 买入时点是 T+1（开盘或收盘），不是 T 日收盘价或当日最低价

## B. 统计正确性

- [ ] B1 n = 横截面天数，不是股票数
- [ ] B2 IC 用秩相关；t 用 **HAC**（重叠前向收益），朴素 t 只作参考
- [ ] B3 每期横截面标的 ≥ 20（低于则剔除该日，并报告剔除了多少天）
- [ ] B4 尝试次数如实统计（参数、持有期、样本段、分类口径各算一次），Bonferroni 门槛与表格标记一致
- [ ] B5 组合模拟的配对差既报**按日期聚类**，也报**持有期重叠校正**（相邻信号日共享 H−1 天行情）；
     判定用更保守的那个，门槛取有效自由度下的 t 临界值，不用 1.96
- [ ] B6 并列因子同分同档；打乱输入顺序结果不变
- [ ] B7 跳空开盘已在止损线下的入场**保留**，按开盘价离场，不得删除
- [ ] B8 非法数值（空、NaN、Inf）、重复日期、重复信号被拦截而非静默归零
- [ ] B9 持有期/成本等参数在入口校验：非空、正整数、互不重复（`--horizons -5` 必须报错，
      过去的版本会拿回看收益算出一张合格的表）；行情列负成交量、空日期同样拦截

## C. 判定完整性

- [ ] C1 IC 分多个持有期（至少 1/5/10/20）看衰减；报告剔除的无效截面天数（因子全同分/收益全相同）
- [ ] C2 滚动分段（≥4 段）报告每段符号
- [ ] C3 **分年拆解**，最近一年单独列出
- [ ] C4 先由价差**符号**决定做多哪一档，再与该方向的多头腿超额和双边成本并列比较（不是只报 t，也不是一律按低−高）
- [ ] C5 集中度：剔除前 1/3/5/10/20 天，**且**回答"那几天事前可否识别"
- [ ] C6 组合模拟：均值、p5/p10/最差、波动、持有天数、按日等权差、聚类 t、重叠校正 t 全部报告；
     并声明它不构成上线证据（无仓位/资金曲线/容量）
- [ ] C7 类别标签回查代码分支，并抽样验证分支条件确实成立
- [ ] C8 每一条被排除的解释都写明"用什么数据排除了它"
- [ ] C9 构造效度（第 0 关）：分数是否存在封顶/托底/分类二次赋值；若有，跨组 rank-IC 不作数，
      只给 L0 描述，排序结论必须组内重算（`scripts/probe_score_construct.py`）
- [ ] C10 池子分解（关 6.5）：组合亏钱时先分清"选股不行"还是"池子选错"；
      报告各池等权收益与被剔除池的过路费，以及四种选法的 alpha 与净值（`scripts/pool_lab.py`）

## D. 结论与交付

- [ ] D1 判级只能是 L0–L5 之一，或明确列出多档并说明适用条件
- [ ] D2 每个数字后挂可重算命令（`vkit` 子命令 + 参数，能被人跑出来对账；跑不出来的数字删掉）
- [ ] D3 附带"数字可信度速查表"：哪些能进产品，哪些不能，为什么
- [ ] D4 边界章节写明未做项（样本外 / 分钟级 / 容量 / 组合层回撤）
- [ ] D5 若 A–C 任一项缺失 → 首页标 **"仅方法演练，不可引用"**，不得作为报价依据或产品承诺
